# Layout ideas (VARIANT mode: "give me three layouts")

Three layouts must come from three **different ideas about the user's main job**, not three skins of one screen. Write each idea as one line a stranger could repeat: "Every channel in one triaged inbox". If two ideas would give the same wireframe, one of them isn't an idea.

## Where ideas come from

| Lever | Ask | Example (chat) | Example (reader profile) |
| --- | --- | --- | --- |
| **The unit** | What is one "thing" on screen? | a channel / a thread / a person | a book / a shelf / a year |
| **The moment** | When does the user open this? | catching up after a meeting | showing their taste to a friend |
| **The order** | What decides what comes first? | time / urgency / mentions | currently reading / rating / date read |
| **The density** | Scan many or read one? | dense stream vs one thread at a time | wall of covers vs one review |
| **The metaphor** | What real thing does it echo? | a desk with stacks | a bookshelf, a diary, a library card |
| **The intensity** | How much of the portfolio shows? | Low: tokens only | High: the book is the structure |

Pick three levers that pull in different directions. A good set usually has one **familiar** layout (the archetype done well), one **reframed** layout (different unit or order), and one **signature** layout (the system's book or scene doing real work, where it fits the content).

## For each idea, before code

1. The idea in one line.
2. What the user does in the first 5 seconds.
3. What it **gives up** (every idea makes something worse; say what).
4. Intensity, and why that level fits this idea.

## Picking one

Pick in terms of the user's main job and where the system holds up, in two sentences: "Take 02: catching up is the main job and the triaged inbox does it in one screen; the rail and Paper stream are where the system is strongest." Not "it looks best".

## Anti-patterns

- Same frame, different colours.
- An idea that is a feature ("with dark mode", "with AI summary").
- Using Book or Scene for a stream, table or dashboard to make a layout "different".
- Three layouts at High. Vary the intensity only when the idea needs it.
